# 📚 Summer Training Material Repository

A comprehensive collection of study material, assignments, solutions, coding practice, and weekly projects completed during my Summer Training Program. This repository serves as both a learning archive and a reference guide for students preparing for university assessments, programming fundamentals, and introductory Machine Learning concepts.

## 📖 Overview

This repository contains all the resources I used and created throughout my summer training. It is organized topic-wise and week-wise to make learning structured and easy to follow.

The primary goal of this repository is to:

* Maintain a well-organized record of my learning journey.
* Document solutions to assignments and practice problems.
* Showcase weekly projects completed during the training.
* Provide a revision resource for future semesters and placement preparation.
* Help other students understand concepts through practical implementations.

## ▶️ How to Use This Repository

1. Clone the repository.

```bash
git clone https://github.com/mohit2814v/Summer-Training-Material.git
```

2. Navigate to the project directory.

```bash
cd Summer-Training-Material
```

3. Open the required folder.

4. Run the Python files using:

```bash
python filename.py
```

or open the Jupyter Notebook files using Jupyter Notebook or Visual Studio Code.
